# Implement Desktop Workspace

Objective: implement a Meridian desktop workspace that behaves like part of the workstation
platform, not an isolated screen.

Constraints:
- Inventory existing WPF shell, workspace, shared controls, view models, services, and tests before
  coding.
- Reuse shared workstation primitives before adding new controls or commands.
- Keep business and workflow logic in services/view models, not views.
- Include loading, empty, error, disabled, busy, stale, and success states.
- Use virtualization, paging, cancellation, and async I/O for large or slow data.
- Add or update focused WPF tests and document the validation command.

Final summary must include files changed, reuse decisions, tests, resource review, and known risks.

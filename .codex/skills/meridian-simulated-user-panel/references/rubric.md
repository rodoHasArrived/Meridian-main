# Persona Rubric

Score each persona on the same six dimensions. Higher is always better. Every score must cite an
artifact observation or an explicitly stated missing-evidence constraint.

## Score Anchors

| Score | Meaning |
| ---: | --- |
| 1 | Critical friction or trust failure blocks the persona's core task. |
| 2 | Material weakness requires workarounds, support, or unacceptable uncertainty. |
| 3 | Workable with caveats; the core task is possible but important friction remains. |
| 4 | Strong and credible; only limited improvement is needed. |
| 5 | Excellent for the persona's job, controls, and operating cadence. |

## Dimensions

| Dimension | Evaluate |
| --- | --- |
| Workflow Fit | Whether the persona can complete the core job with clear state and next actions. |
| Trust / Controls | Whether permissions, approvals, auditability, explanations, and recovery inspire justified trust. |
| Time-to-Value | How quickly the persona reaches a useful, defensible outcome. |
| Data Confidence | Whether source, freshness, lineage, transforms, and evidence are understandable. |
| Extensibility | Whether the workflow fits adjacent processes, exports, integrations, and future depth without brittle workarounds. |
| Learning Curve | How easy the workflow is to learn and retain; a higher score means easier learning. |

## Scoring Rules

- Score only what the artifact bundle supports.
- Use a low score with missing-evidence rationale when the absence itself creates user risk.
- Keep persona ratings independent; do not copy one role's scores to the rest of the panel.
- Do not compute a panel-wide average. Use complaint clusters and tensions for synthesis.
- Never turn simulated scores into claims about customer satisfaction or market demand.

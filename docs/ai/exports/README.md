# AI Context Exports

**Status:** generated-output lane
**Owner:** core-team
**Reviewed:** 2026-06-16

This directory is the default target for Meridian Development Intelligence Framework context snapshots generated by `build/scripts/ai/meridian_context_exporter.py`.

Generated exports are convenience artifacts for AI sessions. They are not canonical source-of-truth documents; update architecture, domain, ADR, and context-pack files first, then regenerate exports when needed.

The exporter includes Meridian's active proof-chain scope, operator workspace names, shared UI/API seams, default deferrals, MDIF source lists, and project inventory. Use the Markdown output for human handoffs and the JSON output for tool or agent context loading.

Example:

```bash
python3 build/scripts/ai/meridian_context_exporter.py --markdown-output docs/ai/exports/LLM_CONTEXT.md --json-output docs/ai/exports/context.json --summary
```

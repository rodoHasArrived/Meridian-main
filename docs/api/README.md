# API Documentation

**Status:** active
**Owner:** core-team
**Reviewed:** 2026-05-30

This folder holds API-oriented documentation that has not yet been migrated into the rebuilt
`docs/reference/` lane. During the documentation rebuild, treat these files as source material for
reference documentation unless a specific API page is still linked as canonical.

## Canonical Destination

- API lookup material should move to or be linked from [Reference](../reference/README.md).
- Generated API output should remain generator-owned and documented from
  [Generated Documentation](../generated/README.md).
- API behavior changes should update the relevant source README, contract docs, or generated API
  artifacts in the same change.

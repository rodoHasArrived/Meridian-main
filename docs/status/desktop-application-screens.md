## Maturity labels

Maturity is intentionally evidence-backed and does not treat a registered descriptor, XAML page, or shell route as readiness by itself. Each inventory row uses one controlled-vocabulary label and names the best currently linked evidence found during this pass.

| Label | Evidence threshold for this inventory |
| --- | --- |
| Ready | Focused tests or acceptance/status evidence cover the screen's current desktop workflow strongly enough to treat the listed capability as ready for normal operator review. |
| Active but partial | A WPF view model/service, shared endpoint/read-model contract, or focused test exists, but the inventory does not claim complete workflow readiness. |
| Fixture/demo-backed | The screen has retained desktop screenshot evidence or demo/fixture evidence, but this pass did not find enough implementation/test evidence to call it active workflow coverage. |
| UI shell only | Retained screenshot evidence shows a visible shell surface, but this pass did not find screen-specific view model/service or contract-backed workflow evidence. |
| TBI | The screen is intentionally to-be-implemented or only has a tracked future-work placeholder. |
| Needs verification | This pass found no permitted evidence source beyond registration, routing, or XAML presence; the row should not be read as ready until backed by implementation, contract, test, acceptance, or screenshot evidence. |

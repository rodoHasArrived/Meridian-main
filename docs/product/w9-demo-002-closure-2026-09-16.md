## The correction this closure absorbs

Acceptance was taken on 2026-08-29 on evidence that overstated one exit criterion. Review on
2026-09-15 found that the seeded market history was written to a demo-only
`{demoRoot}/historical/{SYMBOL}/seeded-trades.jsonl` path that `HistoricalDataQueryService` — the
service every Data desk surface reads through — cannot discover:

- `GetAvailableSymbols()` scans only **top-level** directories of the data root, and `historical`
  fails its `IsLikelySymbolName` check, so the desk's symbol list came back empty.
- `FindDataFilesForSymbol()`'s `historical/` probe is
  `Directory.GetFiles(historicalDir, "*{symbol}*", AllDirectories)`, whose pattern matches **file
  names** rather than directory names, so a symbol-free file name under a symbol directory matched
  nothing.

A freshly seeded demo therefore listed no symbols and returned no prints while all 270 files sat on
disk. The durability test asserted `File.Exists` on the seeded path instead of reading back through
the service, which is why the gap survived acceptance.

The fix merged to `main` on 2026-09-15 as commit `b8dc61ff` (PR 2972): the seeder now builds real
`MarketEvent` trade events, resolves their paths with `JsonlStoragePolicy` and serialises them with
`HighPerformanceJson` — the policy and serialiser `JsonlStorageSink` itself uses — so seeded history
lands in the `{demoRoot}/{SYMBOL}/Trade/{date}.jsonl` partitions a live capture produces. Seeded
events carry `MarketDataSources.Sample`, so bar aggregation attributes the series as sample data.
Re-seeding prunes only the session files its own manifest records, leaving market data an operator
collected into the demo workspace untouched, and a workspace seeded on the previous layout converges
on the readable one. The registry record of that correction merged on 2026-09-16 as `8bdc3cff`
(PR 2973).

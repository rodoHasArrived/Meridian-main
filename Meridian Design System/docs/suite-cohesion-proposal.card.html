Twenty-seven deep screens, one missing product

27 templates · 7 archetypes · 20 production
read end to end, Sep 2026

Individually the screens are finished work — guarded flows, proof contracts, action envelopes, four data states each. Collectively they were 27 dioramas, not one workstation. What was missing is not more depth inside a screen; it is the tissue an operator uses all day: one address book, one clock, one signed-in person, one set of preferences, and loops instead of dead ends. Every item below is a gap with evidence from the tree; tracks A, B, C and D are now closed, and E has its first real loops. Full report, including what is still open: docs/SUITE_COHESION_4_4.md.

E · Dead ends where operators need loops

Part shipped

“I got to the security detail. Now how do I get back to the break that sent me?”

E-1

No way back — now a breadcrumb on every masthead screen. app-map.js declares each drill-in screen’s parent; WorkstationTopbar derives Domain › parent › screen › object from the map and the URL, with a back chevron that appears only when there is real in-suite history or a parent. No per-screen work — the same lever B-5 used for identity. Screens teach it their record’s name, so the crumb reads 1100 · Cash & equivalents, not Account 1100. SecurityDetail still hand-rolls its own header and is the remaining hold-out.

E-2

Handoffs were one-way — now declared both ways. app-map.js › LOOPS holds the returns for eleven object types, ReturnPath renders them, and the flagship loop is wired to real data: JE-1042 ↔ CASE-4181, using the break narrative the reconciliation screen already carried. Each remaining loop is now one field on a seed record.

E-3

Selection died on navigation — fixed on the loop. Reconciliation now reads and writes ?break= and accounting ?entry=, so arriving from a loop opens the right object and Back, new-tab and deep links keep the operator’s place. The other 25 screens still hold filters, sort and open drawers in component state.

E-4

In-flight work is unprotected. ActionQueue unmounts on navigation: leave basket-builder mid-commit and the instruction whose entire purpose is to stay visible until it lands is silently dropped. A suite-level queue plus a navigation guard finishes the pattern the system already argues for.

## Maturity

| Stability | Meaning |
|---|---|
| `stable` | Supported. Breaking changes only in a major, with a migration note and a codemod where the change is mechanical. |

## Token roles

Use role tokens: `--interaction-focus` for focus, `--interaction-selected` /
`--interaction-selected-surface` for selection, `--link` / `--link-hover` for
links, `--semantic-info` for informational state, `--scenario-signal` for scenario
series, and `--brand-signal` for identity. The generic `--accent` remains a palette
entry in the current token CSS, and retained legacy component sources still
reference it; its removal is not a completed migration. Check the current token
closure and [Upgrading](UPGRADING.md) before deleting a compatibility name.
`tokens/parity-manifest.json` describes application name compatibility with
`valuesShared: true`; `scripts/check_token_parity.py` proves value parity with
the browser workstation when the package sits in the monorepo. This census on
its own does not.

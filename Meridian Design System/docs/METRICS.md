## Maturity

`api/families.json` carries a `stability` field per export, declared in `scripts/generate_families.py`:

| Stability | Meaning |
|---|---|
| `stable` | Supported. Breaking changes only in a major, with a migration note and a codemod where the change is mechanical. |
| `release-candidate` | Public and supported, but the shape may still change inside a minor. The `decision/` trio sits here for one release while templates adopt it. |

## Token roles

Terracotta interaction uses are fully reclassified to role tokens across component sources, cards,
guideline cards and template inline styles: focus to `--interaction-focus`, committed selection and
control on-states to `--interaction-selected` / `--interaction-selected-surface`, links and text
buttons to `--link` / `--link-hover`, informational status to `--semantic-info`, scenario series to
`--scenario-signal`, and identity uses to `--brand-signal` and its washes. **Component call sites of
the generic `--accent` are now zero**; it remains only as the white-label palette entry and
deprecated alias through 3.x, and 4.0 removes the generic name. Which token breaking changes ship in
4.0 is declared in the 4.0 release manifest and nowhere else — an older planning document and
`tokens/colors.css` comments must not become two sources of truth.

Template eligibility

Requiring every operating-language primitive on every screen would be consistency theater, so adoption is measured against the cells that carry a design judgment: eligible templates conforming ÷ templates eligible. Every one of the 27 templates is on the record — C-16 in the static gate fails the release if a new screen ships unclassified, because an unclassified template is absent from both terms and would move the printed percentage without anything having been migrated.

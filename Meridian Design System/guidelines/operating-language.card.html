Rule of use · and the anti-pattern it retires
WorkspaceContextBar
Scope is declared once, under the chrome. Every panel below inherits it from the provider.
Never: a period picker in a card header.
LinkedSelectionProvider
Hover previews locally; click, Enter, Space commit; Escape clears. Name the provider with scope when a screen has more than one group.
Never: hover changing a chart.
Datum
Anything judged against a threshold carries that reference inside the plot. Use svg in-plot, to for spans, DatumGroup when labels crowd.
Never: terracotta as a default datum.
ContinuityFrame
Retained evidence stays visible, named, aged, dimmed, and locked. Pass since and it runs its own clock.
Never: a skeleton where a number was.
AnalyticalFigure
Question, unit, as-of, source, condition, readout, method, fallback — or it is a decoration. Tile with AnalyticalFigureGrid under a declared shared scale.
Never: essential values only on hover.
Capsule
Fixed anatomy, honest state, heights from the xs / sm / md / lg ladder so a grid aligns without hand-tuning.
Never: movable/resizable — not yet wired.

Restraint over coverage. A screen adopts the primitives its job needs and no more. Six-for-six everywhere would be consistency theater — a sign-in gate has no analytical scope to declare and a report pack has nothing to select. A primitive used once, gaining nothing from the shared model, is a dependency rather than a language: take it out.

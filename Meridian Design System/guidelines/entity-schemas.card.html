Shared entity schemas

Map your backend to these once at the edge and Blotter, FillsFeed, NotificationCenter, and the tables drop in with no adapter code. Times are UTC (epoch ms or ISO); status is a free string normalized by SeverityBadge; money is unrounded and formatted by Delta/AmountCell. Full reference: guidelines/ENTITY_SCHEMAS.md.

Order

id, createdAt, symbol
side: Buy|Sell
qty, type, limitPrice?
tif: DAY|GTC|IOC|FOK
filledQty?, status
env: live|paper|fixture

Fill

id, orderId?
filledAt, symbol
side: Buy|Sell
qty, price, venue?

Alert

id, firedAt, rule, scope
severity  → SeverityBadge
state: Open|Acked|Closed
value?, threshold?, env?

Run

id, kind, startedAt
completedAt?, status
progress? (0..1)
metrics?, env?

Instrument

symbol (key), name, assetClass?, exchange?, currency?

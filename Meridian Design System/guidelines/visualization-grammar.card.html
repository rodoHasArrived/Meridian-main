Visualization & analytical grammar

Every Meridian visualization answers what changed, compared with what, how certain and current it is, and what to inspect next — in the default view, without hover, detached legends, or explanatory prose. Full law: guidelines/VISUALIZATION_GRAMMAR.md.

Reading path — build in this order

1 · ClaimA testable statement, not a topicClaimHeader
2 · EvidenceOne dominant surface, 60–75% widthTraceChart
3 · ComparisonPrior, benchmark, peer, scenarioPlateGrid
4 · StateFreshness, uncertainty, missingnessDataCondition
5 · DetailSelected value and its evidenceEvidenceInspector
6 · ActionFilter, resolve, save, exportToolbar

Prohibited deviations

Equal-weight dashboard tiles instead of one dominant viewport
A detached legend as the only series key
Hover-only essential values
Independently scaled comparison plates
Force-directed layout for ownership or lineage
Terracotta reused as the default loss / error color
Blank cells standing for missing or not-applicable data
Model uncertainty and data freshness sharing one treatment
Mobile settings placed before the main evidence
Solving density by shrinking labels

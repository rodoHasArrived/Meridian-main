"Sound the same" — pick by role

TokenOn panelUse for
text-secondary 7.1:1 Read it to work — field labels, row labels, side-panel copy.
text-muted 6.1:1 Annotates content — captions, units, timestamps, "last synced".
accent-hover — Lighter — pointer hover.
accent-dim — Darker — pressed / active.
bg-hover — Transient hover — flat neutral shift.
bg-active — Persisting selected state — cool wash.
border — Default hairline.
border-strong — Emphasis — totals, headers, section frames.

Rule of thumb: if the user reads it to do the task → secondary; if it annotates what they read → muted. Full matrix in guidelines/TOKEN_REFERENCE.md.

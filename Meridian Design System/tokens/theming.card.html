Density Variants

Use data-theme-density="terminal|compact|spacious" to adjust spacing & row heights. Terminal is the densest scope, for multi-monitor ops walls.

Terminal
Input row height: 26px
data-theme-density="terminal"
Compact
Input row height: 32px
data-theme-density="compact"
Cozy (default)
Input row height: 40px
data-theme-density="cozy" (default)
Spacious
Input row height: 48px
data-theme-density="spacious"

Usage

<!-- Single brand, default density -->
<html data-brand="indigo">
  <body>...</body>
</html>

<!-- Brand + density -->
<html data-brand="emerald">
  <body data-theme-density="compact">...</body>
</html>

<!-- Or programmatic (JS) -->
document.documentElement.setAttribute('data-brand', 'rose');
document.body.setAttribute('data-theme-density', 'spacious');

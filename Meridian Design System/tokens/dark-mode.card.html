Dark Mode Theme

Meridian supports automatic dark mode via prefers-color-scheme: dark or manual override with data-theme="dark" attribute.

How to Use

Automatic: Dark mode activates when user's OS has prefers-color-scheme: dark enabled (system settings).
Manual override: Add data-theme="dark" to the <html> or <body> tag.
Example: <html data-theme="dark">

Light Mode (Default)

Canvas: #DEE3EA

Text: #22272E

Accent: #2F6F8F

Best for: Daytime, outdoor use, high ambient light.

Dark Mode

Canvas: #0E1113

Text: #E5EAEF

Accent: #5790BE (cooler blue for night)

Best for: Nighttime, low-light environments, reduced eye strain.

Implementation Notes

  • No manual switching in code: OS preference is automatic. Only override data-theme="dark" if user explicitly requests dark mode.
  • Accent color: Becomes a cooler blue in dark mode (#5790BE) for night-friendly contrast. Primary actions remain clear.
  • Border colors: Become lighter in dark mode (#45505C) to remain visible on dark canvas.
  • Transitions: Background and color shift smoothly (200ms) when theme changes.
  • All components inherit: Button, Input, Modal, Table — all automatically adapt to dark mode via CSS variables.

Testing

Test dark mode on your system:

  • macOS: System Preferences → General → Appearance → Dark
  • Windows: Settings → Personalization → Colors → Dark
  • Linux: GNOME Settings → Appearance → Dark
  • Browser DevTools: Cmd+Shift+P (or Ctrl+Shift+P) → "Emulate CSS media feature prefers-color-scheme"

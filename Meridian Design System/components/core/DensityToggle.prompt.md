DensityToggle — operator control for the density token scopes (`body[data-theme-density="terminal" | "compact" | "spacious"]`). Terminal is the densest scope for multi-monitor ops walls; compact tightens rows and padding for dense monitoring; spacious loosens for review; default clears the attribute. Writes the attribute onto a target element (document.body by default), optionally persisting the choice to localStorage. Segmented, flat, no transitions.

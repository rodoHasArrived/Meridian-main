Disclosure — the depth contract for a workstation screen. `DisclosureProvider` owns one dial per screen (`summary` | `full`), per-region overrides, and operator-pinned collapse; it persists arrangement to `mds.disclosure.<screenId>` and mirrors the screen dial into `?detail=` so a shared link carries the depth the sender was reading at. `DetailDial` renders the dial — no `region` for the screen dial (it belongs in the chrome beside density, never in the work plane), `region="evidence"` for a region override with a reset back to the screen. `DisclosureRegion` is a collapsible region whose header is a standing report: count, worst severity and freshness render identically collapsed or open, so depth is never concealment — and at summary depth it states how many fields it withheld with a reveal. `DetailOnly` wraps forensic detail and says what it is holding back. `atDepth(tier, detail)` is the one predicate: `tier: "full"` hides at summary, untiered always shows. Use for: tiering columns and fields, collapsing secondary regions, a screen-level summary→forensic dial. Never use to hide an object's identity, a figure the screen is about, or a violation.

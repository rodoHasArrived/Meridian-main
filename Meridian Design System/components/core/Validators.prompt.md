# Validators

`Validators` returns `true` for valid input and a message for invalid input. Use `required` separately from optional length checks; numeric zero and boolean false are present values. Currency validation accepts finite monetary numbers or complete decimal strings, optional dollar prefix, valid thousands groups and accounting parentheses. Malformed suffixes, inconsistent signs, nonfinite values and excess decimals are errors; no partial numeric parse can authorize an edit. Named date formats round-trip local calendar days and honor inclusive bounds. `compose` returns the first failure. These client-side checks support feedback and never replace service-owned financial or authorization checks. `FormValidation.Validators` is a separate null-on-success contract; do not interchange their success sentinels.

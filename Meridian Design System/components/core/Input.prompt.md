Mono text field on white paper — 34px tall, hairline border, teal-blue focus ring. Optional small-caps label and error state.

```jsx
<Input label="Symbol" placeholder="AAPL" />
<Input label="Quantity" defaultValue="-200" error="Exceeds position limit" />
```

Values are mono (`--font-data`) — symbols, ids, quantities. Hover darkens the border; focus adds the blue ring; error turns it red.

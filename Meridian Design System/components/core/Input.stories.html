Input

Text input field with optional error state, label, and placeholder. Use for forms, searches, and data entry.

Props

Prop Type Default Description
label string — Field label (optional). Displays above the input.
value string "" Input value. Controlled component.
onChange function — Change event handler: (e) => {}
placeholder string "" Placeholder text shown when field is empty.
error string — Error message. Shows red border + message when present.
disabled boolean false Disable input and prevent editing.
type "text" | "email" | "password" | "number" | "date" "text" Input type. Affects keyboard and validation.

Examples

1. Basic Input
<Input label="Name" placeholder="Enter your name" />
2. Controlled Input (with state)
const [value, setValue] = useState(""); <Input label="Email" value={value} onChange={(e) => setValue(e.target.value)} placeholder="you@example.com" />
3. With Error State
Password must be at least 8 characters
<Input label="Password" type="password" error="Password must be at least 8 characters" placeholder="Min 8 characters" />
4. Disabled Input
<Input label="Account ID" value="ACC-12345" disabled />
5. Different Input Types
<Input type="date" label="Transaction date" /> <Input type="email" label="Email" placeholder="user@domain.com" /> <Input type="number" label="Amount" placeholder="0.00" />

Validation

Use FormValidation for consistent error handling:
const errors = FormValidation.validateField(value, [FormValidation.Validators.required, FormValidation.Validators.email]);

Accessibility

✓ Labels: Always use the label prop or associated <label> element.
✓ Focus visible: Clear blue focus ring on keyboard navigation.
✓ Error announcement: Use aria-invalid="true" + aria-describedby for error messages.
✓ Placeholder: Never use placeholder as the only label.

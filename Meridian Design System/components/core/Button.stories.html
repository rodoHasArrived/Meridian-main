Button

Primary, ghost, danger, and link button variants. Use for all user actions: submit, cancel, navigation, and more.

Props

Prop Type Default Description
variant "primary" | "ghost" | "danger" | "link" "primary" Visual style. Primary is the one solid action per screen; ghost is the paper secondary (most buttons); danger resolves to red on hover; link is text-only.
size "sm" | "default" | "lg" | "icon" "default" Button size. Small for compact toolbars, large for prominent CTAs, icon for a 32×32 icon-only button.
disabled boolean false Disable the button and prevent interaction.
onClick function — Click event handler.
children ReactNode — Button label or content.
className string "" Additional CSS classes.

Examples

1. Basic Usage
<Button variant="primary">Save</Button> <Button variant="ghost">Cancel</Button> <Button variant="danger">Delete</Button> <Button variant="link">Learn more</Button>
2. Sizes
<Button size="sm">Small</Button> <Button size="md">Medium</Button> <Button size="lg">Large</Button>
3. Disabled State
<Button disabled>Disabled</Button>
4. Form Submission
<form onSubmit={handleSubmit}> <Input label="Name" /> <Button variant="primary" type="submit"> Submit </Button> </form>
5. Modal Actions
<Modal open={open}> <ModalBody>Are you sure?</ModalBody> <div style={{display: 'flex', gap: 8}}> <Button variant="primary" onClick={handleConfirm}> Confirm </Button> <Button variant="ghost" onClick={handleCancel}> Cancel </Button> </div> </Modal>

Accessibility

✓ Keyboard accessible: Buttons are focusable and respond to Enter/Space keys.
✓ ARIA attributes: Set aria-disabled="true" on disabled buttons.
✓ Focus visible: Clear focus outline on keyboard navigation.
✓ Color contrast: All variants meet WCAG AA+ standards.

Usage Guidelines

  • Primary: Use for the main action on a screen (submit, save, confirm). Only one per screen.
  • Ghost: The paper secondary — use for alternative and tertiary actions (apply filters, export, cancel, close). Multiple allowed; this is what most buttons on a screen should be.
  • Danger: Destructive actions (delete, revoke, close position). Ghost styling with red text; resolves to a red wash on hover.
  • Link: Text-only, for the lowest-emphasis actions (learn more, view details) inline with content.
  • Size: sm for toolbars/inline actions, lg for prominent CTAs, icon for a 32×32 icon-only button. default is the base size.
  • Disabled: Always provide context for why a button is disabled (e.g., "Fill in all required fields first").

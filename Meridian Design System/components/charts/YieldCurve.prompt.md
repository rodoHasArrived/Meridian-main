YieldCurve — term-structure line chart (yield vs tenor) for rates and bond surfaces (Basket Builder, fixed-income research). Tenors position on a sqrt-of-years x-scale so the money-market end doesn't crush; an optional comparison series (prior date, benchmark) overlays dashed with a legend; an optional tenor-pair spread readout ("2Y–10Y") prints in bp, red with an inversion note when negative. Flat, token-driven.

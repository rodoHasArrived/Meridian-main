ChartFrame — shared axis/plot chrome for the chart family. Real-pixel rendering (self-measured width, never transform-scaled), stacked panes with nice-tick gridlines and a value rail, x labels that thin correctly when sparse, legend row, crosshair vline. Charts draw only marks via a render prop receiving geometry (`x(i)`, `pane(key).y(v)`). Also exports `AxisChip` and `AXIS_FONT`; the kernel exports `Fmt` (price/currency/bp/volume/date formatters).

A11y (3.5): `ariaLabel` names the figure (svg `role="img"`), `ariaDescription` links a one-sentence reading, `accessibleData` renders a visually-hidden data table/list. Unlabeled frames stay presentational. All indexed-series wrappers (EquityCurve, DrawdownChart, Histogram, BarChart, CandleChart, Waterfall, Scatter, Depth, YieldCurve) forward all three.

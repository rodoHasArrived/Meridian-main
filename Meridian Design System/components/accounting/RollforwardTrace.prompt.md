Opening → movements → closing, with the arithmetic proved in place. The instrument for book value, carrying value, par, NAV, or any balance a reviewer must reconstruct.

```jsx
<RollforwardTrace opening={9875000} closing={9878812.40} currency="USD"
  movements={[
    { label:"Discount accretion", value:3812.40, linkLabel:"Journal", onOpen:openJournal },
    { label:"Principal movement", value:0 },
  ]} />
```

Give every movement a resolve-to link (calculation, journal, schedule, lot, rule, evidence). When the stated closing disagrees with the movements the strip turns to "Out by …" — never suppress that. Use `StatementTable` for a presented financial statement and `LedgerTable` for postings; `RollforwardTrace` explains one balance.

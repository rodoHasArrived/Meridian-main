AnnotationLayer — notes anchored to a grid cell, series point, ledger line or object header. Wrap the anchored thing in `AnnotationAnchor({anchor:{kind,ref,label}})`; a ¶ marker with the count appears (on hover when empty). Each note records the object version and the operator picks: **follow** (goes stale when the object changes; `Still holds at vN` re-affirms) or **pin** (bound to that version). `AnnotationPanel` lists All · Stale · Pinned for the evidence rail. One `AnnotationProvider({objectId, objectVersion, author, annotations, onChange})` per object in view.

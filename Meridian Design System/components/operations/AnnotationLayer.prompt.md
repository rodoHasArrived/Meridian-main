AnnotationLayer — notes anchored to a grid cell, series point, ledger line or object header. Wrap the anchored thing in `AnnotationAnchor({anchor:{kind,ref,label}})`; a ¶ marker with the count appears (on hover when empty). Each note records the object version and the operator picks: **follow** (goes stale when the object changes; `Still holds at vN` re-affirms) or **pin** (bound to that version). `AnnotationPanel` lists All · Stale · Pinned for the evidence rail. One `AnnotationProvider({objectId, objectVersion, author, annotations, onChange})` per object in view.

Use a stable `objectId` when a detail pane switches between accounts or securities. The provider retains a separate note set per object; switching back restores that object's local edits. `annotations` seeds the first visit to an object and does not replace later edits. Pass the current object's seed collection: notes naming another object are ignored, and notes without an `objectId` belong to the object being seeded. Hook-created notes default to the current object and version and receive IDs that cannot collide with persisted seed IDs.

GlobalSearch

The masthead has always rendered a full-width field reading “Search symbols, runs, commands…”. Until 4.4 it had no handler on any screen in the suite — the widest affordance in the chrome was a picture. This is what it opens: a typeahead over the current screen’s objects plus every destination in the app map, grouped, keyboard-first. ds-base.js mounts it and binds both the field and /, so screens write nothing.

Where the rows come from

Objects — the screen’s own. MeridianOperatorLayer.build() publishes its resolver to .current, so a screen that already declares objects is searchable with no extra work. A screen that declares none says so in the empty state rather than pretending.

Go to — every non-hidden screen in templates/_scaffold/app-map.js, with its G chord as the right-hand meta. Identical on all 27 screens, because it is one list.

Mounting it yourself

<x-import component-from-global-scope=
  "MeridianDesignSystem_205d17.GlobalSearch"
  open="{{ searchOpen }}"
  on-close="{{ closeSearch }}"
  resolve="{{ resolveObjects }}"
  destinations="{{ destinations }}"
  hint-size="0,0"></x-import>

Only needed to place it somewhere other than the masthead — the default mount is automatic.

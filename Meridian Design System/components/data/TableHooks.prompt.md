# TableHooks

Call the four members as React hooks within a component. `useTableState` owns source rows, local search/filter/multi-sort/group state and named view snapshots. Retained view state is restored before persistence; inaccessible or malformed browser storage must not disable local controls. `useTableColumns` owns schema-keyed order, geometry, visibility and pinning while retaining current column labels/renderers. `useRowSelection` uses stable keys and the current row order, including shift ranges and explicit select-across-pages mode; never infer loaded selection from the size of a retained off-page key set. Clear selection when the business scope changes. `useAsyncTableData` debounces query/sort requests, rejects late superseded reads even when fetchers ignore abort, and supports replacement or append behavior. Its fetcher must return source rows and totals; the hook never recomputes financial values or authorizes writes.

OptimisticCell — EditableCell's write counterpart. A committed edit shows as Provisional (dashed, struck prior beside it) until the provider's `commit` resolves; a throw rejects it and the value falls back WITH the reason shown, never silently. Confirmed edits show `Revert…`, which demands a reason; `OptimisticRowBar` tallies a row's or a selection's edits and reverts every confirmed one under a single reason. Wrap in `OptimisticProvider({commit, revert, onSettle})`; without one the cell keeps a private ledger and confirms at once.

Batch compensation unwinds newest first; keep that order when applying `prior` values in a revert handler or `onSettle`. Entries beneath a newer provisional/reverting write, or a newer confirmed write outside the selected batch, wait for that write to settle or be reverted first. This prevents an older undo from overwriting a newer value on the same field.

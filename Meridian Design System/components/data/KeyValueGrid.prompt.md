Label-over-value fact grid for entity summaries and detail panes.

```jsx
<KeyValueGrid columns={3} items={[
  { label: "FIGI", value: "BBG000B9XRY4" },
  { label: "Exchange", value: "XNAS" },
  { label: "First bar", value: "2004-01-02" },
]} />
```

Eyebrow labels, mono values. Use 2–4 columns inside a `PanelSurface`.

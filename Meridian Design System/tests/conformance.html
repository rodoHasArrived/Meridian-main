Loads each @dsCard in an iframe and asserts: it mounts, no component threw, no duplicate DOM id, every control has an accessible name, every <button> has a type, no positive tabindex, nothing transitions all, dialogs are named, the first control takes visible focus, and a card that publishes an adoption figure recomputes it from its own rows. Three at a time; the run takes a few minutes. Append ?cards=all to the URL to start it automatically, ?cards=Operations for one group.
